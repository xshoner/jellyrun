## 에셋·효과음 추가 최적화 (v24)

- v23 대비 실제 이미지 응답량: **24,449,009 → 3,274,966바이트 (86.6% 감소)**. 게임이 로드하는 37개 이미지의 RGBA 픽셀 기준 메모리: **133,050,312 → 53,148,536바이트 (60.1% 감소)**. GPU 전체 메모리나 실제 기기 FPS 측정값은 아닙니다.
- 캐릭터는 원래 해상도의 무손실 WebP, 몬스터·장애물·포털은 절반 해상도의 투명 WebP를 사용합니다. 원본 스프라이트 좌표를 가로·세로 각각 보정해 홀수 크기 시트의 프레임 경계도 유지합니다. 보너스 젤리·아이템은 최대 96px, 배경은 최대 1280×512로 생성합니다. 원본 PNG는 보존하지만 게임에서는 다운로드하지 않습니다.
- 젤리 효과음은 종류 전체에 걸쳐 60ms 간격으로 제한하고 종류별 재사용 풀은 최대 2개입니다. 모바일 동시 효과음은 최대 8개로 제한합니다. 대기 중인 음악은 `preload=none`, 음량 0에서는 재생을 멈춥니다.
- 터널 타일과 파티클 배열을 재사용하고, 자석이 없을 때 불필요한 거리 계산을 생략합니다. 반복 점수 팝업은 최대 32개 작은 Canvas에 캐시합니다. 외부 웹폰트 다운로드와 실행 중 폰트 교체도 제거했습니다.
- 재생성: `python tools/optimize-sprites.py`, `python tools/optimize-backgrounds.py` (Pillow 필요). 캐시 버전은 v24입니다.
- 검증: 게임 84개, 이벤트 44개, 오디오 12개 및 성능 회귀 검사. `node test-browser.cjs`는 Chromium/WebKit 세로·가로 환경에서 37개 에셋 로딩, 축소 시트의 실제 소스 좌표, 점수 글자 캐시 재사용과 게임 동작을 검사합니다.
- 비교 재현: Playwright 설치 후 `node test-render-benchmark.cjs <v23 체크아웃 경로>`. 동일 WebKit 합성 장면의 draw 명령 제출 중앙값은 이번 실행에서 0.217ms → 0.183ms였으며, 이 수치는 iPhone Safari 실기기의 표시 FPS를 의미하지 않습니다.
- 참고: [Canvas 최적화 지침](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas), [미디어 preload 동작](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/preload).

## 모바일 렌더링 최적화 (v23)

- 터치 기기는 960×540으로 렌더링하며 게임 좌표와 물리 계산은 1280×720, 120Hz를 유지합니다. 2초 동안 프레임 지연이 반복되면 해상도를 단계적으로 낮추며 하한은 640×360입니다. 화면 크기·회전·충돌 범위는 변하지 않습니다.
- 모바일에서는 매 프레임 Canvas 블러와 색상 필터를 사용하지 않습니다. 보호막·레이저·화상 본체와 폭탄 점멸 경고는 유지하고, 잔상 및 장식 파티클 수를 제한합니다.
- 배경 12장의 런타임 WebP는 총 3,292,938바이트로 원본 PNG 대비 89.9% 작고, 디코딩 픽셀 메모리는 약 47% 감소합니다. 원본은 보존합니다. 재생성: `python -m pip install Pillow`, `python tools/optimize-backgrounds.py`.
- HUD 텍스트는 값이 바뀔 때만 갱신하고 게이지는 너비 대신 transform으로 갱신합니다. PWA 캐시 및 진입 파일 버전은 v23입니다.
- 검증: `node test-game.cjs`, `node test-events.cjs`, `node test-audio.cjs`, `node test-performance.cjs`. 실제 브라우저 엔진 검증: Playwright 설치 후 `node test-browser.cjs` (Chromium/WebKit, 휴대폰 세로/가로, 효과·입력·일시정지·해상도 전환). Windows WebKit 검증은 실제 iPhone Safari의 GPU·발열·저전력 모드 측정을 대신하지 않습니다.

## 최신 패턴·스페셜 몬스터 변경

- 일반 젤리 배열에는 각 젤리마다 5% 확률로 보너스 젤리 1~5 중 하나가 섞이며, 각각 150점입니다. 기존 포털 젤리 100점과 희귀 젤리 300점은 유지됩니다.
- 젤리 배열은 아치·물결·계단으로 시작해 2스테이지에 이중 줄·연속 아치, 3스테이지에 다이아몬드·교차 물결, 4스테이지에 왕관 형태가 추가됩니다. 장애물 내부와 점프 도달 범위를 벗어나는 배치는 보정하거나 생략합니다.
- 장애물은 1스테이지에 기본 5종, 2스테이지에 적층·지그재그·2초 슬라이드, 3스테이지에 조합·긴 틈·3초 슬라이드, 4스테이지에 터널을 추가합니다. 5스테이지부터 복합 패턴 비중을 높이며, 높이·연속 개수·패턴 간 회복 시간에는 상한과 하한을 둡니다.
- 해적왕 등장 시 20% 확률로 몸체와 불꽃이 1.4배인 스페셜 해적왕, 야구선수 등장 시 10% 확률로 몸체와 공이 1.3배인 스페셜 야구선수가 나옵니다. 충돌 범위도 같은 비율로 확대하며 공격 속도와 피해량은 유지합니다.
- 폭발 이미지는 순간적으로 좌우·상하 진동과 회전을 보인 뒤 점차 안정됩니다. 이미지 진동은 피해 판정 위치를 바꾸지 않습니다.
- 검증: `node test-game.cjs`, `node test-events.cjs`, `node test-audio.cjs`.

## 조작
- Space / ↑: 점프, 공중에서 다시 누르면 2단 점프. 키를 길게 눌러도 자동 연속 점프하지 않습니다.
- ↓: 누르는 동안 슬라이딩. 터치 화면에는 JUMP / SLIDE 버튼이 있습니다.
- P / Esc: 일시정지 / 계속하기. 다른 창으로 이동하거나 탭이 숨겨지면 자동으로 일시정지합니다.
- 상단 소리 버튼으로 효과음을 켤 수 있습니다.

## 점수·이동
- 젤리 점수는 기본 10, 중급 25, 스페셜 100입니다. 상대 등장 가중치는 1 : 0.25 : 0.05입니다.
- 스페셜 젤리는 60×60px로 기본 젤리의 가로·세로 2배입니다. 획득 판정도 같은 크기입니다.
- 플레이 시간 0.1초마다 거리 1m와 점수 1점이 누적됩니다. 총점 = 거리 점수 + 젤리 점수. 일시정지·사망·게임오버 중에는 누적되지 않습니다.
- 표시 거리는 요청된 시간 환산 기준으로, 스테이지·스피드 효과와 무관하게 0.1초당 1m입니다.
- 45초마다 스테이지가 오르고 이동 속도가 이전 스테이지보다 13% 증가합니다.
- 점프 최고 높이는 184.8px입니다. 2단 점프의 이론상 최고 높이는 369.6px이며, 하강은 기존 물리보다 같은 높이에서 15% 빠릅니다.
- 빈 직선 구간에도 일정 간격으로 젤리가 등장합니다. 슬라이딩 구간의 젤리는 낮게 배치하고, 폭탄·틈·바닥 장애물과 겹치는 직선 젤리는 생략합니다.

## 아이템
- 보호막: 15초, 공격 1회 방어. 아이스 레이저도 막으며 소모됩니다.
- 에너지: 즉시 30% 충전, 최대 100%.
- 부활: 치명적 피해 또는 추락 시 10%로 부활. 동시에 1회만 보유합니다.
- 자석: 10초, 캐릭터 격자 크기 반경 3배의 젤리를 끌어당깁니다.
- 스피드: 8초, 이동 속도 3배·무적.
- 거대화: 10초, 크기 3배·무적.
- 무적·거대화 중에도 두 번 점프할 수 있습니다. 지속형 아이템 재획득은 시간 갱신입니다. 스피드·거대화는 함께 적용됩니다.
- 효과 종료 시 3회 점멸합니다. 즉시 충전은 획득 시, 부활은 실제 발동 시 점멸합니다. 획득 효과 설명은 3초간 표시합니다.
- 등장 확률: 보호막 20초/60%, 에너지 25초/40% 및 60초 확정, 부활 120초/80% 및 240초 확정, 자석 17초/70%, 스피드 30초/60%, 거대화 40초/65%.

## 일반 장애물과 함정
- 일반 충돌 피해는 25%, 피격 후 1.2초간 추가 피해를 방어합니다.
- 가로 2·3개, 세로 2·3·4단, 점프와 슬라이딩을 번갈아 하는 조합이 등장합니다. 가장 높은 4단은 272px입니다.
- 단일 공중 장애물, 2·3·5초 연속 슬라이딩을 섞어 배치합니다. 연속 슬라이딩 후보의 30%는 점프 장애물로 대체합니다.
- 연속 슬라이딩은 진입부터 해당 시간 동안 유지되도록 속도 변화에 맞춰 길이를 조정합니다. 종료 후 남은 몬스터는 화면 밖까지 자연스럽게 이동합니다. 위쪽 어두운 덮개는 없습니다.
- 끊어진 길의 짧은 틈은 1단, 긴 틈은 2단 점프로 건넙니다. 짧은 틈은 `barrier4.png`, 긴 틈은 `barrier5.png`를 사용하며 캐릭터 도착 1초 전에 두 번째 프레임으로 튀어 오릅니다. 이때 각각 `crash.mp3`, `croco.mp3`를 재생합니다.
- 추락은 게임오버이지만 부활 보유 시 안전한 바닥에 복귀합니다. 일반 보호막은 추락을 막지 않습니다. 스피드·거대화 중에는 빛의 발판으로 통과할 수 있습니다.

## 폭탄
- `barrier2.png`를 사용하며 13초마다 68% 확률로 등장합니다.
- 등장부터 붉게 점멸하고, 가까워질수록 점멸 속도가 증가합니다. 근접하면 첫 이미지 → 점화 두 번째 이미지 → 폭발 세 번째 이미지 순서로 재생합니다.
- 폭발은 기준 150px의 1.8배인 270×270px입니다. 위와 좌우로 커집니다. 뜨거운 중심의 피해 판정은 150×220px이며, 1단 점프 높이보다 높아 2단 점프가 필요합니다. 연기·가장자리 불티는 피해 판정에서 제외하여 회피 여유를 둡니다.
- 폭탄 피해는 25%입니다. 보호막·무적·부활이 적용됩니다. 긴 슬라이딩 및 특수 몬스터 공격과 겹치지 않도록 성공한 등장 요청을 잠시 보관할 수 있습니다.

## 특수 몬스터: 동시에 하나만 등장
- 해적왕·얼음 괴물·야구선수는 같은 종류도 중복 등장하지 않습니다. 성공한 등장 요청은 대기열에 보관합니다. 앞선 몬스터와 발사체가 모두 지나간 뒤 다음 몬스터를 등장시킵니다.
- 위험한 필수 슬라이딩·점프 조합과 특수 공격이 겹치지 않도록 공격 시작 시 공간을 확보합니다. 공격 후에는 몬스터 몸체가 일반 지상 장애물로 다가옵니다. 몸체 피해는 25%입니다.

### 해적왕 (`monster01.png`)
- 30초마다 75% 확률, 120초마다 확정 등장.
- 등장 즉시 공격하며 0.34초 간격으로 3연발, 30% 확률로 4연발을 발사합니다.
- 매 발사 순간의 캐릭터 높이를 겨냥하며 불꽃 속도는 현재 이동 속도의 2배입니다. 피해는 40%입니다.

### 얼음 괴물 (`monster02.png`)
- 40초마다 80% 확률 등장.
- 첫 번째 이미지로 2.5초 조준하며 예고선과 “점프로 피한다”를 표시합니다. 이 시간 안에서 `3 → 2 → 1`, 발사 순간 `Bang!!`을 크게 표시합니다.
- 반드시 두 번째 이미지에서 1.5초 레이저를 발사합니다. 세 번째 이미지 마무리 0.35초 후 지상 장애물이 됩니다.
- 광선은 포구에서 화면 왼쪽 끝까지 파란 빛으로 굵어졌다 사라집니다. 시작 0.12초와 소멸 0.15초에는 회피 여유를 두며, 가운데 1.23초에 빙결 판정이 있습니다. 현재 2단 점프로 피할 수 있는 경로를 검증했습니다.
- 피격하면 직접 피해 대신 3초 빙결입니다. 캐릭터 자세·위치·조작은 멈추고 맵과 장애물 충돌은 계속됩니다. 얼음 결정·반짝임·남은 시간이 표시됩니다. 같은 레이저로 빙결 시간을 연장하지 않습니다.

### 야구선수 (`monster03.png`)
- 20초마다 50% 확률, 150초마다 확정 등장.
- 첫 번째 준비 이미지 0.65초 후 두 번째 타격 이미지에서 이펙트와 큰 야구공을 발사합니다. 이후 세 번째 이미지로 전환해 지상 장애물로 남습니다.
- 공은 발사 순간의 캐릭터 위치를 향하며 속도는 현재 이동 속도의 2.8배입니다. 피해는 40%입니다.
- 피해를 받으면 2초 동안 점멸·어지럼 효과와 함께 패닉에 빠져 점프·슬라이딩 입력이 막힙니다. 맵·물리·다른 장애물 충돌은 계속됩니다.
- 보호막·무적은 공과 패닉을 방어합니다. 부활하면 패닉을 남기지 않습니다. 스피드·거대화를 획득하거나 부활하면 빙결·패닉이 풀립니다. 일시정지 시 상태 시간도 멈춥니다.

## 순위표와 앱 설치
- 게임 종료 후 2~12자의 닉네임을 입력하면 Firebase Firestore의 `scores` 컬렉션에 스코어, 이동거리, 플레이 시간, 날짜를 저장합니다.
- 순위표에는 상위 10개 기록을 표시하며, 내 기록이 10위 밖이면 표 맨 아래에 실제 순위를 추가로 표시합니다.
- 웹 앱 매니페스트와 서비스 워커를 제공하여 지원 브라우저에서 `앱으로 저장`할 수 있습니다. 설치된 앱은 가로 전체 화면으로 실행됩니다.
- 모바일에서 게임을 시작하면 전체 화면과 가로 방향 잠금을 요청하며, 방향 잠금을 지원하지 않는 브라우저에서도 게임 화면 자체를 가로로 회전해 표시합니다.

## 전체 화면과 이벤트

- 스피드·거대화는 각 효과의 남은 시간이 3초 이하일 때 캐릭터가 점멸합니다.
- 야구공 피격은 즉시 40% 피해와 1.5초 위치 고정 경직을 적용합니다. 공중에서도 높이와 수직 속도를 보존합니다.
- 해적왕 불은 즉시 30% 피해에 이어 5초간 불꽃과 매초 2% 화상 피해를 적용합니다. 재피격은 화상 시간을 갱신하며 중첩하지 않습니다. 보호막·무적으로 막은 공격에는 화상이 없고, 스피드·거대화 획득과 부활은 화상을 해제합니다. 일시정지와 보너스 스테이지에서는 화상 시간이 보존됩니다.

- PC는 브라우저 너비·높이의 70% 안에 16:9 게임 화면을 표시하며 주변은 검은색입니다. 모바일 전체화면은 기존 동작을 유지합니다.
- 배경음악은 bgm001 → bgm002 → bmg003 → bmg004 → bgm005 순서로 반복하며 전체 볼륨의 70%로 재생합니다.
- PC의 Esc, 모바일의 뒤로가기 또는 게임 우측 상단의 화면 줄이기는 게임을 일시정지하고 페이지 내부 화면으로 돌아옵니다. 우측 상단의 일시정지/플레이 버튼으로 이어서 진행할 수 있습니다.
- 악어 트랩은 접근 시 두 번째 프레임이 아래쪽을 기준으로 1.8배 높이로 솟습니다. 슬라이딩 장애물은 마지막 타일까지 온전한 이미지를 표시합니다.
- 스피드·거대화 중 장애물을 파괴하면 일반 젤리의 두 배인 20점을 받습니다. 연속 슬라이딩 장애물은 파괴한 타일마다 한 번만 점수를 지급하며, 파괴된 타일의 충돌도 제거합니다.
- 갱신된 `bgm/item_speed.mp3`는 스피드 효과 8초 동안 반복 재생되며 마지막 2초에 페이드 아웃합니다. 일시정지 시 효과 시간과 음원도 멈춥니다. 거대화가 완료되면 `big effect.mp3`를 추가 재생합니다.
- 고블린은 17초마다 50% 확률로 등장 요청됩니다. 네 프레임 달리기 애니메이션과 함께 캐릭터 속도의 2배로 접근하고 접촉 피해는 40%입니다. 50% 확률로 캐릭터와 화면 오른쪽 끝 사이의 40~70% 지점에서 한 번 2초간 정지한 뒤 4배속으로 돌진합니다. 등장 시 `goblin.mp3`, 재돌진 시 `goblin2.mp3`를 재생합니다.
- 몬스터는 앞선 장애물과 트랩이 지나갈 때까지 기다립니다. 등장 때문에 기존 장애물이나 젤리를 삭제하지 않으며, 서로 충돌하는 공격을 겹쳐 생성하지 않습니다.
- 일반 진행 시간 90초마다 35% 확률로 포탈이 등장 요청됩니다. 캐릭터까지 남은 거리가 접근 구간의 30% 이내가 되면 두 번째 프레임으로 열립니다. 등장 시 `portal.mp3`를 재생합니다.
- 포탈 접촉 시 1초간 원래 게임을 정지하고 전환 효과 후 보너스 스테이지로 들어갑니다. `bonus_bg1.png`와 `bonus_bg2.png`가 이어지고, 15초 동안 장애물 없이 다섯 종류의 100점 보너스 젤리를 지상과 점프 높이에 배치합니다.
- 입장·퇴장 시 `bonus_effect.mp3`를 재생합니다. 보너스 종료 후 원래 캐릭터 위치·배경·장애물·젤리·남은 아이템 시간에서 이어지며 1.5초 동안 점멸 무적이 적용됩니다. 일반 스테이지 시간과 아이템 효과 시간은 보너스 동안 보관됩니다.
- 일반 진행 시간 30초마다 30% 확률로 보너스 젤리 한 개가 랜덤 등장하며 일반 스테이지에서는 300점입니다.
